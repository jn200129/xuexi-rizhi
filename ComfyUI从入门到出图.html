一、ComfyUI 是什么

ComfyUI 是一个节点式的 Stable Diffusion / FLUX 前端。每一步（加载模型 → 编码提示词 → 采样 → 解码 → 保存）都是一个可视化节点，用连线组装成一条工作流。

相对 SD WebUI (A1111)，它的优势：

  • 支持所有新模型 day-1（SD1.5、SDXL、Illustrious、FLUX、Video）
  • 生成的 PNG 自带工作流元数据，把图拖回 UI 就能还原当时全部参数
  • 有完整 HTTP API 和 Python 库，方便脚本化 / 批量出图 / 集成到其他系统
  • 低 VRAM 优化好，8GB 显卡也能跑 SDXL / Illustrious

本文所有内容基于 ComfyUI v0.27.0 portable + RTX 5070 (12GB) + Windows 11 实测。

二、环境搭建（Windows）

1. 下载 portable 版

官方地址：GitHub Releases

如果 GitHub 拉不动，用代理或者 Cloudflare WARP（warp-cli.exe connect 后能直连 GitHub 1.5-2 MB/s）。下载 ComfyUI_windows_portable_nvidia.7z，解压到 D:\ComfyUI\（约 6GB，Python + PyTorch + CUDA 全打包，不用装环境）。

2. 启动

进入 D:\ComfyUI\ComfyUI_windows_portable\，根据显卡选启动脚本：

显卡启动脚本说明
NVIDIA 通用run_nvidia_gpu.bat常规启动
RTX 40/50 系run_nvidia_gpu_fast_fp16_accumulation.bat开 fp16 累加加速，~30% 提速
无独显run_cpu.bat极慢，仅测试

启动后浏览器打开 http://127.0.0.1:8188 即是 UI。

三、核心工作流：文生图 7 节点

一个最小可用的文生图工作流由 7 个节点组成，通过 5 类连线传递数据。

节点作用一览

#节点类型输入 → 输出关键参数
①CheckpointLoaderSimpleckpt 文件 → MODEL / CLIP / VAE选底模
②CLIPTextEncode (正)CLIP + 文本 → CONDITIONING正面提示词
③CLIPTextEncode (负)CLIP + 文本 → CONDITIONING负面提示词
④EmptyLatentImage空 → LATENT分辨率、batch
⑤KSamplerMODEL + 正/负 + LATENT → LATENTseed / steps / cfg / sampler / scheduler
⑥VAEDecodeLATENT + VAE → IMAGE潜空间 → RGB
⑦SaveImageIMAGE → PNG文件名前缀

cd D:\ComfyUI\ComfyUI_windows_portable\ComfyUI\models\checkpoints

curl -L -C - -o Illustrious-XL-v2.0.safetensors `

加速三件套：

  • hf-mirror.com 替代 huggingface.co
  • curl -L -C -：-L 跟随重定向，-C - 断点续传（大文件必备）
  • Cloudflare WARP 连着，直连 GitHub 也能跑到 1.5 MB/s

五、提示词写法（关键中的关键）

Illustrious / Pony / NoobAI 系全部认 Danbooru 标签，语法：snake_case、逗号分隔、按重要度排序。写自然语言效果差得多。

正面提示词模板

masterpiece, best quality, amazing quality, very aesthetic, absurdres,
1girl, solo,
chihaya_anon, bang_dream, mygo,
pink_hair, short_hair, side_ponytail, blue_eyes,
casual_clothes, hoodie,
holding_electric_guitar, guitar,
stage, spotlight, neon_lights, purple_theme,
dynamic_pose, looking_at_viewer, cowboy_shot, cinematic_lighting

顺序规则

负面提示词模板（通用）

worst quality, low quality, bad quality, normal quality, lowres,
bad anatomy, bad hands, bad fingers, extra fingers, missing fingers,
bad proportions, deformed, disfigured, mutated,
watermark, signature, text, error, jpeg artifacts,
blurry, out of focus, multiple views, cropped

权重语法

  • (tag:1.2) — 权重放大 1.2 倍（1.0-1.3 之间为佳，超 1.5 容易崩）
  • [tag] — 权重减到约 0.9
  • 组合示例：(masterpiece:1.1), (pink_hair:1.2), 1girl
underscore 规则：Danbooru 标签空格用下划线代替，比如 purple eyes 要写成 purple_eyes；不加下划线部分模型能容错，但精度会掉。

七、HTTP API 批量出图

ComfyUI 内置 HTTP API，POST /prompt 提交工作流 JSON 就能触发一次出图。适合脚本化 / 批量出图 / 参数遍历。

API 端点

端点方法作用
/promptPOST提交工作流，返回 prompt_id
/history/{prompt_id}GET查询状态、拿输出文件名
/view?filename=...&subfolder=...&type=...GET下载已生成的图
/system_statsGET查询服务器状态、VRAM

出图流程

Python 模板脚本

import json, time, uuid, urllib.request, urllib.parse
from pathlib import Path

SERVER = "127.0.0.1:8188"
CLIENT_ID = str(uuid.uuid4())
OUT = Path(r"D:\ComfyUI_setup\outputs")
OUT.mkdir(parents=True, exist_ok=True)

WORKFLOW = {
    "3": {"inputs": {"seed": 0, "steps": 30, "cfg": 6.0,
                     "sampler_name": "euler_ancestral", "scheduler": "karras",
                     "denoise": 1.0, "model": ["4", 0],
                     "positive": ["6", 0], "negative": ["7", 0],
                     "latent_image": ["5", 0]},
          "class_type": "KSampler"},
    "4": {"inputs": {"ckpt_name": "Illustrious-XL-v2.0.safetensors"},
          "class_type": "CheckpointLoaderSimple"},
    "5": {"inputs": {"width": 832, "height": 1216, "batch_size": 1},
          "class_type": "EmptyLatentImage"},
    "6": {"inputs": {"text": "", "clip": ["4", 1]}, "class_type": "CLIPTextEncode"},
    "7": {"inputs": {"text": "worst quality, ...", "clip": ["4", 1]},
          "class_type": "CLIPTextEncode"},
    "8": {"inputs": {"samples": ["3", 0], "vae": ["4", 2]},
          "class_type": "VAEDecode"},
    "9": {"inputs": {"filename_prefix": "gen", "images": ["8", 0]},
          "class_type": "SaveImage"},
}

def queue(wf):
    body = json.dumps({"prompt": wf, "client_id": CLIENT_ID}).encode()
    req = urllib.request.Request(f"http://{SERVER}/prompt",
        data=body, headers={"Content-Type": "application/json"})
    return json.loads(urllib.request.urlopen(req).read())["prompt_id"]

def wait(pid):
    while True:
        h = json.loads(urllib.request.urlopen(f"http://{SERVER}/history/{pid}").read())
        e = h.get(pid)
        if e and e.get("status", {}).get("completed"):
            return e["outputs"]
        time.sleep(1)

wf = json.loads(json.dumps(WORKFLOW))
wf["6"]["inputs"]["text"] = "masterpiece, best quality, 1girl, chihaya_anon, ..."
pid = queue(wf)
for _, out in wait(pid).items():
    for img in out.get("images", []):
        q = urllib.parse.urlencode({"filename": img["filename"],
            "subfolder": img["subfolder"], "type": img["type"]})
        data = urllib.request.urlopen(f"http://{SERVER}/view?{q}").read()
        (OUT / img["filename"]).write_bytes(data)

八、MCP 集成（让 AI 直接驱动 ComfyUI）

comfyui-mcp（artokun/comfyui-mcp）是一个把 ComfyUI 封装成 MCP server 的 npm 包。装完后 Claude / ChatGPT / 本地 Ollama 都能用自然语言指挥 ComfyUI 出图。

配置

在 Claude Code 的项目根目录（比如 C:\Users\jiangnan）建 .mcp.json：

{
  "mcpServers": {
    "comfyui": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "comfyui-mcp"],
      "env": {
        "CIVITAI_API_TOKEN": "",
        "COMFYUI_PATH": "D:\\ComfyUI\\ComfyUI_windows_portable\\ComfyUI"
      }
    }
  }
}

生效方式：重启 Claude Code + 弹窗信任 → 工具 generate_image / create_workflow / enqueue_workflow / view_image 就会出现，AI 端可以直接调用。

自测

timeout 8 npx -y comfyui-mcp
# → [comfyui-mcp] Found ComfyUI on port 8188
# → ComfyUI MCP server running on stdio

十二、常见坑与排错

症状原因解决
启动黑屏 / VRAM 溢出底模太大用 fp8 版本，或加 --lowvram
图全糊prompt 像人类语言换成逗号分隔的 Danbooru 标签
手指全崩底模不认手加负面 bad hands, extra fingers，或换 Illustrious/SDXL
FLUX 图烧成一片白CFG 不是 1改回 cfg=1.0
换模型后 UI 里不显示节点缓存页面刷新，或重启 ComfyUI
中文 prompt 效果差底模是英文训练用英文 Danbooru 标签，或装翻译节点
下 HuggingFace 超时直连被墙换 hf-mirror.com
GitHub 拉不动直连慢Cloudflare WARP warp-cli.exe connect

十三、进阶方向

  • LoRA — 小模型（几十~几百 MB）叠加在底模上，微调画风 / 角色 / 姿势。Civitai 上一堆二次元 LoRA
  • ControlNet — 用姿势图 / 线稿 / 深度图控制构图
  • Regional Prompt — 一张图分区域用不同 prompt（左边一个角色右边一个）
  • Hires Fix / Upscale — 先出 832×1216 再放大到 1664×2432
  • ADetailer / FaceDetailer — 自动检测脸部 → 局部重绘 → 提升脸的清晰度
  • Video / AnimateDiff — 出动图 / 视频，可做视频转二次元风格
  • FLUX Kontext — FLUX 的图生图（局部改、换服装、换背景）
